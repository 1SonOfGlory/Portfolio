# Project source index

Source repositories for Jabess Omane’s portfolio. Repository READMEs distinguish implemented behavior, test coverage, and open limitations.

- [DecisionLens](https://github.com/1SonOfGlory/DecisionLens): Counterfactual search, feature costs, and explicit graph assumptions. Research prototype with open evaluation issues.
- [Kasa](https://github.com/1SonOfGlory/Kasa): Telephony, context retrieval, policy checks, and tool execution. 25 service tests passed using fixtures and mocks.
- [The Representational Imprint](https://github.com/1SonOfGlory/Representational-Imprint): Association metrics, baseline checks, and a development-pilot notebook. Eight unit tests passed; research is ongoing.
- [Articulate](https://github.com/1SonOfGlory/Griot-Labs-Articulate-AI): Communication-practice interface and FastAPI backend. Learning outcomes have not been evaluated.
- [Strata](https://github.com/1SonOfGlory/Strata-biometric-verification): Browser extension for recording and replaying writing events. It does not determine authorship or detect generated text.
- [Bank of Ghana data audit](https://github.com/1SonOfGlory/Bank-of-Ghana-Data-Audit): CSV profiling and data-quality checks. Source datasets are not redistributed.
- [Articulate: earlier prototype](https://github.com/1SonOfGlory/Articulate_ai): Earlier React and TypeScript version from AI Studio.
- [Customer-support prototype](https://github.com/1SonOfGlory/Customer-Support-Prototype): FastAPI, keyword retrieval, session storage, and optional text and speech services.
- [Soil report prototype](https://github.com/1SonOfGlory/Soil-Report-Prototype): Workbook rules, measurement classification, and document generation. No agronomic validation is claimed.
- [Vesto](https://github.com/1SonOfGlory/Vesto): Apparel storefront and local demonstration-order handling.
- [Kwans Concepts](https://github.com/1SonOfGlory/Kwans-Concepts): Website source with deployment setup documented separately.
- [Tee Shop](https://github.com/1SonOfGlory/Tee-Shop): Storefront source; payment and hosting services require configuration.
- [Creative Hands Media](https://github.com/1SonOfGlory/Creative-Hands-Media): Static website and booking interface; private media and customer records are excluded.
- [GuardianBridge](https://github.com/1SonOfGlory/GuardianBridge): Laravel and React scaffold. Product-specific functionality remains to be implemented.
